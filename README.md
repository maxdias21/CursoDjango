# 🐍 Django Complete Course

Projeto desenvolvido durante meus estudos completos de Django com foco em backend, templates e organização de aplicações web.

## 📌 Sobre o projeto

Este repositório foi criado para praticar conceitos importantes do ecossistema Django, incluindo:

* arquitetura MVT,
* criação de apps,
* templates,
* sistema de notícias,
* internacionalização,
* testes,
* e organização de projetos maiores.

O projeto foi dividido em múltiplos apps para simular uma aplicação real e facilitar manutenção e escalabilidade.

## 🛠️ Tecnologias utilizadas

* Python
* Django
* HTML5
* CSS3
* Pytest

## 📂 Estrutura do projeto

* `authors/` → gerenciamento de autores
* `community/` → funcionalidades da comunidade
* `news/` → sistema de notícias
* `tag/` → gerenciamento de tags
* `tests/` → testes automatizados
* `utils/` → funções auxiliares
* `locale/` → internacionalização
* `website/` → configurações principais

## 📚 Aprendizados

Durante o desenvolvimento aprendi:

* estruturação de projetos Django,
* templates e renderização,
* rotas e views,
* organização de apps,
* internacionalização (i18n),
* testes automatizados,
* manipulação de banco de dados,
* e boas práticas de backend.

## 🎯 Objetivo

O principal objetivo deste projeto foi construir uma base sólida em Django e compreender como aplicações backend maiores podem ser estruturadas.
